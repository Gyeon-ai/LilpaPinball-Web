## Images

Marbles and the app icons are pixel-art "rice-cake bat" balls drawn by code (`src/lilpaBat.ts`, copied from the design prototype; `assets/lilpa-pinball-icon-*.png` were rendered from the same code).
They were drawn for this project; reference pictures supplied by the user were used only for features and are not included.
